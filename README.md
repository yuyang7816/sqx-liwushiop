## **1. 项目简介**

**省钱兄送礼物商城全套开源系统**（「送礼物商城」）是一套围绕礼品选购、个性卡面、祝福语、送礼领取、商城下单、钱包充值与分销收益的礼物电商业务系统，采用前后端分离架构，服务端、管理端、用户端全套代码开源。

服务端基于 **Spring Boot 2.6.11**（**Java 8**）多模块构建，负责接口、数据库，以及支付、短信、对象存储等外部能力。  
管理端基于 **Vue 3 + Element Plus + Vite** 开发，供运营人员在电脑浏览器中使用。  
用户端基于 **uni-app**（**uView Plus**）开发，覆盖手机网页和微信小程序，应用名称是「送礼物商城」。

本仓库为服务端、管理端、用户端全套源码。

## **2. 用户端能力概览**

底部四个主入口：**首页、商城、订单、我的**。

| 模块 | 能做什么 |
|---|---|
| 首页 | 搜索、轮播与金刚区、个性卡面、特价好礼与商品推荐、进入送 TA 礼物流程 |
| 商城 | 按分类浏览商品、进入商品详情与规格选择 |
| 订单 | 查看购买 / 送礼相关订单与订单详情 |

## **4. 快速开始**

建议顺序：**先服务端，再管理端，最后用户端。** 管理端和用户端都要等服务端已经启动，才能登录和加载数据。

### **4.1 服务端**

安装 JDK 8、Maven、MySQL 5.7 / 8.0。可选安装 Redis（当前配置默认关闭）。导入 [`GiftMall-server/db/gift-mall.sql`](GiftMall-server/db/gift-mall.sql)（演示库；系统配置中的客服 / 支付 / 短信等密钥已清空，菜单权限保留），再在 `GiftMall-server` 目录启动服务端（启动类 `SqxAdminApplication`），默认端口 **9191**，上下文路径 `/sqx_fast`。  
开发库名默认 `gift-mall`，连接信息见 `GiftMall-server/sqx-admin/src/main/resources/application-dev.yml`。  
详细步骤见 [服务端运行教程](docs/服务端-运行教程.md)。

### **4.2 管理端**

安装 Node.js 18 或以上（Vite 5 推荐），在 `GiftMall-admin` 里执行安装并启动。开发默认端口 **8087**。  
详细步骤见 [管理端运行教程](docs/管理端-运行教程.md)。

### **4.3 用户端**

用 HBuilderX 打开 `GiftMall-uniapp`，运行到浏览器或微信开发者工具。  
详细步骤见 [用户端运行教程](docs/用户端-运行教程.md)。

后台演示账号一般为：**admin** / **123456**（以导入库中数据为准，导入后请立即修改）。  
短信、微信、支付宝、对象存储相关密钥需要自行申请。申请入口写在 [用户端功能说明](docs/用户端-功能说明.md) 末尾。

## **6. 目录结构**

仓库根目录放三端代码、说明和协议。编译出来的 `target`、`dist`、`unpackage`、`node_modules` 是运行时生成的，不需要改。

### **6.1 仓库根目录**

| 路径 | 是什么 |
|---|---|
| `GiftMall-server` | **服务端**。多模块 Maven 工程；接口、支付、短信、文件上传、礼品商城业务等都在这里；演示库在 `GiftMall-server/db/gift-mall.sql` |
| `GiftMall-admin` | **管理端**。运营人员在电脑浏览器里打开的后台 |
| `GiftMall-uniapp` | **用户端**。消费者用的手机应用，也能在电脑浏览器里预览 |
| `docs` | 三端的功能说明和运行教程 |
| `LICENSE` | Apache License 2.0 全文 |

### **6.2 服务端 `GiftMall-server`**

| 路径 | 是什么 |
|---|---|
| `sqx-admin` | 启动模块。入口 `SqxAdminApplication.java`；配置在 `src/main/resources` |
| `sqx-auth` | 认证相关能力 |
| `sqx-common` | 公共能力。核心工具、Redis、文件、支付等 BOM / 子模块 |
| `sqx-domain` | 领域仓储与 Mapper |
| `sqx-modules/sqx-system` | 系统模块。管理员登录、角色、菜单、字典、配置、App 用户等 |
| `sqx-modules/sqx-gift-mall` | **礼物商城核心业务**。商品 / 分类 / 购物车 / 订单 / 卡面 / 祝福 / 场景、优惠券、钱包、发票、分销提现、轮播、反馈、支付回调等 |
| `db/gift-mall.sql` | 演示库初始化脚本（密钥已清空，菜单权限保留） |

### **6.3 管理端 `GiftMall-admin`**

| 路径 | 是什么 |
|---|---|
| `src/views/login` | 登录页（「省钱兄礼物商城系统」） |
| `src/views/system` | 业务与系统页面。用户、订单、商品、财务、优惠券、首页装修、发票、系统配置等 |
| `src/views/exampleViews` | 示例与部分业务列表页 |
| `src/views/bigScreen` | 数据大屏相关页面 |
| `src/router` | 页面地址和菜单对应关系 |
| `src/store` | Pinia 登录状态等临时数据 |
| `src/http` | Axios 请求封装 |
| `vite.config.js` | 开发端口（默认 `8087`）与接口代理 |

### **6.4 用户端 `GiftMall-uniapp`**

| 路径 | 是什么 |
|---|---|
| `pages` | 底部四个主入口：首页、商城、订单、我的，以及登录注册等 |
| `my` | 分包页面。送礼 / 领取、卡面、购物车与商品详情、钱包、团队收益、开票、设置等 |
| `common` | 接口地址、公共逻辑 |
| `components` | 页面里重复使用的组件 |
| `static` | 图标、默认图片 |
| `uni_modules/uview-plus` | 界面组件库 **uView Plus**，负责按钮、输入框、轮播、弹窗等 |
| `pages.json` | 有哪些页面、底部导航怎么排 |
| `manifest.json` | 应用名称「送礼物商城」、微信小程序 AppId 等 |

## **7. 核心特性与技术栈**

### **7.1 核心特性**

· **送礼主流程：选卡面 → 选礼物 → 写祝福 → 支付 → 对方领取**  
· **商城分类浏览、商品详情、规格 SKU、购物车下单**  
· **优惠券领取与使用、收藏与搜索**  
· **钱包充值、提现申请与资金明细**  
· **邀请分销、团队与收益展示**  
· **电子发票申请与开票记录**  
· **后台商品 / 订单 / 卡面祝福 / 财务 / 权限与系统配置**  
· **服务端统一处理登录、订单、支付结果与业务入账**

每项怎么用，见 [用户端功能说明](docs/用户端-功能说明.md)、[管理端功能说明](docs/管理端-功能说明.md)、[服务端功能说明](docs/服务端-功能说明.md)。

版本以仓库里的配置文件为准。没写死版本号的，按运行教程安装对应大版本即可。

### **7.2 服务端**

| 类别 | 技术 | 版本 | 用来做什么 |
|---|---|---|---|
| 语言 | **Java** | **1.8** | 整个服务端。不能换成 11 或 17 |
| 框架 | **Spring Boot** | **2.6.11** | 提供网页接口，端口 `9191`，路径 `/sqx_fast` |
| 构建 | **Maven** | 3.6 及以上 | 多模块下载依赖、编译、启动 |
| 数据库 | **MySQL** | 5.7 / 8.0 及以上 | 业务数据。配置库名默认 `gift-mall` |
| 数据库访问 | **MyBatis-Plus** | 3.5.3.2 | 读写表 |
| 连接池 | **Druid** | 1.2.x | 管理数据库连接 |
| 缓存 | **Redis / Redisson** | 可选 | 当前默认关闭；打开后用于登录状态等 |
| 管理端登录 | **Apache Shiro** | 1.4.0 | 后台账号、角色、菜单权限 |
| 用户端登录 | **JWT** | 0.9.1 等 | 用户登录后的凭证 |
| 接口文档 | **Swagger** | 2.7.0 | 浏览器打开 `swagger-ui.html` 查看接口 |
| JSON | **Fastjson2** | 2.0.41 | 接口数据格式 |
| 工具库 | **Hutool** | 5.8.16 | 日期、字符串等常用处理 |
| 对象存储 | 阿里云 OSS 等 | 随文件模块 | 可选。密钥要自己申请 |
| 支付 | 微信支付、支付宝、余额 | 随支付模块 | 下单、回调。密钥要自己申请 |

### **7.3 管理端**

| 类别 | 技术 | 版本 | 用来做什么 |
|---|---|---|---|
| 运行环境 | **Node.js** | 18 及以上（Vite 5 推荐） | 安装依赖、启动开发网站 |
| 页面框架 | **Vue** | 3.5 | 后台每一个页面 |
| 构建 | **Vite** | 5.4 | 开发时热更新，默认端口 `8087` |
| 界面组件 | **Element Plus** | 2.8 | 表格、表单、弹窗、菜单 |
| 页面跳转 | **Vue Router** | 4.4 | 登录页、首页和各业务页的地址 |
| 状态 | **Pinia** | 2.2 | 记住是否已登录 |
| 请求 | **Axios** | 1.7 | 把操作发给服务端 |
| 图表 | **ECharts** | 5.5 | 数据统计 / 大屏相关图 |
| 样式 | **Sass** | 1.78 | 后台样式 |
