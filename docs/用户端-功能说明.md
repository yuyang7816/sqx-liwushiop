# 用户端功能说明

用户端是消费者在手机或电脑网页里打开的那个应用。窗口标题是「送礼物商城」。底部一直有四个按钮：**首页、商城、订单、我的**。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

## 这个端是给谁用的

- **消费者**：浏览礼品、送 TA 礼物、商城下单、看订单、用钱包、邀请好友、申请开票。
- **收礼人**：通过分享链接查看礼物，填写地址并领取。
- **平台工作人员不使用这个应用。** 审核提现、改轮播、管商品与系统配置，在电脑上的管理端做。

## 首页

打开就是首页。

- **搜索**：按关键字搜商品。
- **顶部轮播 / 金刚区**：宣传图与快捷入口。内容来自管理端「首页装修」。
- **个性卡面**：展示可选卡面，可进入全部卡面。
- **特价好礼 / 商品推荐**：浏览礼品，进入详情。
- **场景 / 对象 / 预算筛选**：按送礼场景等条件找礼物。

从首页可进入「送 TA 礼物」流程。

## 商城

底部「商城」按分类浏览商品。左侧分类、右侧列表，可进商品详情、选规格、加入购物车或直接购买 / 送礼。

## 送礼主流程

核心路径：

**选卡面 → 选礼物 → 写祝福 → 支付 → 分享给好友 → 对方领取填地址 → 商家发货 → 确认收货**

- **送 TA 礼物**：选择卡面、商品与祝福语，生成送礼订单。
- **支付**：可选余额、微信、支付宝（取决于环境与后台密钥）。
- **送好友**：支付成功后分享礼物链接或小程序卡片。
- **领取详情**：收礼人查看卡面与祝福，填写收货地址后领取；也可拒绝（以当前版本页面为准）。

付成功后，微信或支付宝会通知服务端，订单才会变成已支付并进入「待赠送」。付完钱立刻关页面、通知还没到时，订单可能要等一会儿才变。

## 购买和支付

商品详情或购物车结算时，可以选择优惠券，并选择支付方式。可选哪些方式，取决于当前运行环境和后台有没有配齐密钥：

- **余额 / 零钱**：扣「我的钱包」里的钱，不经过微信或支付宝。余额不够就不能选。
- **微信支付**：拉起微信支付。需要商户号、密钥，以及小程序或公众号的 AppId。
- **支付宝**：在支持的环境里拉起支付宝。需要应用编号和密钥。

普通自购与送礼单在服务端状态机上略有不同：送礼单支付后进入「待赠送」，自购单进入已付款履约流程。详见 [服务端功能说明](服务端-功能说明.md)。

## 订单

底部「订单」分「我购买的 / 我收到的」。

- **我购买的**：待付款、待赠送、已赠送、待发货、待收货、已完成、退款等。
- **我收到的**：查看别人送给自己的礼物订单与物流。

待支付订单可以在详情里继续支付或取消。订单数据存在自己的服务器里，不是微信订单中心。

## 登录、注册和找回密码

登录相关页面在 `pages/public`：

- **微信登录**：小程序 / App 里常用。要配好小程序 AppId 和密钥。
- **手机号 + 密码登录**。
- **注册**：手机号、短信验证码、密码。验证码是服务端发出的短信。
- **忘记密码**：改密码同样要短信验证码。

没配短信密钥，或短信签名没审核通过时，验证码发不出去，就无法用验证码注册。这时页面会停在发送失败，不是网络坏了。

## 我的

未登录时，头像旁边是「登录」。登录后显示昵称等信息。

常见入口：

- **收藏 / 购物车 / 收到礼物**：快捷统计与列表入口。
- **我的钱包**：余额、充值、提现、明细、提现记录、绑定收款账号。
- **邀请好友 / 我的团队 / 我的收益**：看邀请码、分享海报，查看下级与分销收益。佣金不是微信自动转账。
- **开具发票**：选择可开票订单、填写抬头、查看开票记录与说明。
- **联系客服**：按管理端系统配置走电话、企业微信、小程序客服或二维码。
- **隐私政策、用户协议**：正文由后台维护。
- **设置中心**：问题反馈、注销、退出登录等。

注销是提交注销申请，管理端「注销管理」里能看到，不是点一下账号立刻从数据库消失。

## 这个端真正会连到外面的服务

短信、微信、支付宝、图片存储、地图的密钥填在管理端「系统配置」，由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 能力 | 什么时候用到 | 没配好会怎样 |
|---|---|---|
| 短信 | 注册、找回密码 | 验证码发不出去 |
| 微信支付 | 购买、送礼、充值 | 无法拉起微信付款 |
| 支付宝 | 支持的环境里选择支付宝 | 无法拉起支付宝 |
| 对象存储 / 文件上传 | 头像、收款码等上传 | 上传失败 |
| 微信小程序登录 / 分享 | 小程序登录、送礼分享 | 登录或分享失败 |
| 地图选点 | 领取时填收货地址 | 可能只能手填地址 |

## 这些是站内能力

- 首页轮播、分类、卡面与商品列表展示
- 购物车、收藏、搜索
- 订单列表和详情（不含第三方支付本身）
- 邀请关系与收益展示
- 帮助文章、协议正文
- 开票申请与记录（审核在管理端）
- 提现申请本身（打款在管理端审核后处理）
