# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `GiftMall-admin` 文件夹。程序名称是「省钱兄礼物商城系统」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经在 **9191** 端口正常运行，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 Node.js **18** 或 **20**（Vite 5 推荐，不要用过旧的 14）：https://nodejs.org/

安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18` 或 `v20`，以及 `8.x` 以上。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

开发时，网页请求会先打到本机的 `/sqx_fast`，再由 Vite 代理转到真正的服务端。

用记事本打开 `GiftMall-admin/vite.config.js`，找到 `server.proxy` 里的 `/sqx_fast`。现在的目标多半是线上地址。改成下面这一行，原来的 `target` 可以留成注释：

```javascript
target: 'http://127.0.0.1:9191/',
```

只改这一处地址。下面的 `rewrite` 不要动，它负责把 `/sqx_fast` 去掉再转给服务端。`port` 保持 `8087`。保存。

另外，登录页验证码图片目前可能写死了线上地址。打开 `GiftMall-admin/src/views/login/index.vue`，找到加载 `captcha.jpg` 的那一行，改成：

```text
http://127.0.0.1:9191/sqx_fast/captcha.jpg?uuid=
```

后面拼上原来的 `uuid` 参数即可。要测本地上传时，各页面里写死的 `.../sqx_fast/file/upload` 也要改成本机地址。

改完之后，如果网站已经在运行，要先停掉再启动，修改才会生效。

## 第 2 步：安装依赖

在 `GiftMall-admin` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `GiftMall-admin` 文件夹里执行：

```powershell
npm run dev
```

窗口里会出现本地地址。默认端口是 **8087**，配置里 `open` 是打开的，浏览器一般会自己弹出。没有自动打开时，手动打开：

http://localhost:8087

登录页上应能看到「省钱兄礼物商城系统」，以及一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个 PowerShell 窗口也要一直开着。

## 怎样算成功

用演示账号登录：

- 账号：**admin**
- 密码：**123456**

（以导入库中数据为准，导入后请立即修改。）

登录成功后能看到运营数据概览，左侧有菜单，就说明管理端已经连上服务端。

## 常见问题

**验证码图片裂了，登录失败**  
服务端没启动，或 `vite.config.js` / 登录页验证码地址还指向线上。按第 1 步改成本机 `9191`。

**页面能开，但列表全是空的或接口报错**  
打开浏览器 F12 → Network，看请求是不是打到 `127.0.0.1:9191`。若仍是线上域名，说明代理没改或没重启。

**Node 版本太旧**  
Vite 5 需要较新的 Node。建议用 18 或 20。

管理端能做什么，见 [管理端功能说明](管理端-功能说明.md)。服务端与用户端见 [服务端运行教程](服务端-运行教程.md)、[用户端运行教程](用户端-运行教程.md)。
